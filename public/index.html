❓ FAQ

What is QuestStarter?
A free tool that turns a project idea into a scoped MVP, tech stack, 6-level build plan and copy-paste prompts for AI coding tools.

Is it free?
Yes, no signup needed.

Which tools do the prompts work with?
Cursor, Claude Code, Codex, Windsurf, ChatGPT and any AI coding assistant.

Can I share my quest?
Yes. Press Share to copy a link that rebuilds your quest for anyone.

Does it work for Unity or Godot games?
Yes. Game ideas that mention Unity get a Unity 6 (C#) plan, ideas that mention Godot or 3D get a Godot 4 plan, and both include an MCP server so Claude Code or Cursor can edit scenes directly. Other game ideas get Phaser 3 for the browser. Cozy and sim games get a progression-focused MVP instead of combat.
